# Análisis Integral de Producción y Ventas 2026

## Descripción

Proyecto de análisis de datos desarrollado utilizando PostgreSQL, SQL y Power BI.

## Objetivo

Analizar información de producción y ventas durante el año 2026 para obtener indicadores y hallazgos relevantes para la toma de decisiones.

## Herramientas

- PostgreSQL
- SQL
- Power BI
- Git
- GitHub

## Análisis SQL

El proyecto incluye 15 análisis orientados a producción, ventas, productividad, cumplimiento de metas y comparación entre producción y ventas.

## Power BI

Se desarrollará un dashboard interactivo para visualizar los principales indicadores y resultados del análisis.
